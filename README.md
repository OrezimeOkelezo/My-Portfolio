# Orezime Okelezo | Full-Stack Developer Portfolio

A responsive personal portfolio website with a restrained visual palette, animated 3D-inspired hero, project cards, contact links, and a working light/dark theme switch.

## Run locally
Open `index.html` in a browser. The site is static and does not require a build step.

## Deploy with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The repository's Pages settings will show the final URL.

## Before using this as a job application portfolio
- Add verified education, work experience, and a concise professional bio.
- Confirm the technology list reflects your actual proficiency.
- Add remaining live demo URLs and project screenshots where available.
- Add a CV file only when you have a current, accurate CV ready.

Only the Ozi Furniture live site is linked as a live demo because that URL was previously supplied. Other project cards link to their source repositories. Starred third-party repositories are not represented as your own work.
